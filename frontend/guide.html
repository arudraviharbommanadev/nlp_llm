Overview

What this system is

This project is a local multi-model study assistant built with FastAPI, a plain HTML/CSS/JavaScript frontend, SQLite storage, and Ollama-based local model execution.

It accepts a user request, detects the intent, creates a task plan, routes the task to the most suitable local model, streams progress to the interface, and lets the user save, reopen, export, and delete chat sessions.

Built

What we made

A local chat workspace with session history.
An orchestrator that classifies intent and assigns models.
A streaming backend that exposes execution stages to the UI.
A session system with save, load, export, and delete per chat.
A compact planner panel that shows secondary intents and task plans.
A guide page documenting the whole project.

Workflow

How the request flows

1. User input

The user enters a prompt in the chat box.

2. Preprocessing

The backend normalizes the text, tokenizes it, and extracts useful focus terms.

3. Orchestration

The orchestrator detects the main intent, optional secondary intents, task type, and whether retrieval is needed.

4. Task planning

The request is turned into one or more tasks with assigned models and execution order.

5. Model routing

The task is routed to the selected Ollama model based on intent.

6. Streaming updates

The UI receives stage updates such as intake, orchestration, routing, and final response.

7. Response output

The assistant answer is shown in the chat and can be copied, spoken, saved, or exported.

Usage

How to use the app

Open the app in the browser.
Type a request such as explanation, coding help, quiz, math, or summary.
Watch the planner and pipeline update while the backend processes the request.
Read the answer and use copy or speak if needed.
Click End Session to save the current chat.
Use the sidebar to reopen, export, or delete saved chats.

Models

Models used and purpose

Intent / Task Model Purpose
Coding qwen2.5-coder Code generation, debugging, implementation help
Explanation mistral Concept teaching, reasoning, clear answers
Deep reasoning mistral Planning, comparison, retrieval-heavy or multi-step flows
Math llama3 Math-focused problem solving in the current setup
Quiz / Summary / Rewrite / Translate phi3 Lightweight structured and concise output tasks
Fallback phi3 Used when a lighter safe fallback is needed

Technical

Technical details

Backend framework: FastAPI.
Frontend stack: HTML, CSS, JavaScript with no frontend framework.
Database: SQLite in data/chat_history.sqlite3.
Inference runtime: Ollama.
Session export formats: PDF and DOCX.
Pipeline output is streamed from /chat/stream as newline-delimited JSON.
The backend stores messages, session metadata, and orchestrator runs.
The orchestrator uses heuristic intent scoring and task mapping.
